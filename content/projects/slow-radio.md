**Slow Radio** is an homage to stations that play weather instead of playlists.

Field recordings are collected with a portable recorder, tagged with location
and time of day, then crossfaded live in the browser using the Web Audio API
so there are never any hard cuts between environments.

One listening session feedback: *"I fell asleep to the Norway coastal wind and
woke up to a French meadow. 10/10."* That's the whole design brief.
